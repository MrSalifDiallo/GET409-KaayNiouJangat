MASTERCLASS — PROMPT ENGINEERING
Le Prompt Engineering — Pourquoi ca change tout

Definition : L'art de formuler des instructions a un LLM pour obtenir le resultat le plus precis, le plus utile et le mieux formate possible. Votre valeur ajoutee en tant que 'pilote de systeme intelligent'.

1

2

3
Zero-Shot
Few-Shot
Chain-of-Thought
Instruction directe
Apprentissage par l'exemple
Raisonnement etape par etape
Vous donnez une instruction sans aucun exemple. L'IA repond avec sa connaissance brute. Simple, rapide, mais parfois trop generaliste.
Vous donnez 2-3 exemples du format attendu avant votre vraie question. L'IA 'apprend' le pattern et l'applique. Resultat plus precis et formate.
Vous demandez a l'IA de decomposer son raisonnement avant de repondre. Reduit drastiquement les hallucinations. Ideal pour les analyses complexes.
Quand : questions factuelles, premieres explorations, tests rapides.
Quand : vous voulez un format specifique, des reponses coherentes, des classifications.
Quand : problemes a plusieurs variables, analyses strategiques, diagnostics.

PROMPT ENGINEERING
Few-Shot — Apprendre par l'exemple
2-3 exemples suffisent a imposer un pattern de pensee a l'IA

Principe : Vous montrez a l'IA ce que vous attendez avant de poser votre vraie question. Elle 'apprend' le format, le style, la longueur et le niveau de detail a partir de vos exemples — sans que vous ayez a tout expliquer.

EXEMPLE 1

Entree A → Sortie A (au format attendu)

EXEMPLE 2

Entree B → Sortie B (meme format)

VRAIE QUESTION

Entree C → ???  (l'IA complete en imitant A et B)

CAS CONCRET — Appliquez sur votre secteur ce soir

Donnez 2 exemples Defi → Solution dans votre secteur, puis demandez a l'IA de completer un 3eme defi que vous avez identifie.

PROMPT ENGINEERING
Chain-of-Thought — Faire raisonner l'IA
Decomposer le raisonnement etape par etape reduit les hallucinations

SANS Chain-of-Thought

AVEC Chain-of-Thought

Prompt : "Quelle solution pour les pertes post-recolte au Senegal ?"
Prompt : "Reflechis etape par etape : 1) cause du probleme 2) obstacle financier 3) solution adaptee"
Reponse : Solution directe, souvent trop simple ou non adaptee au contexte local. Risque d'hallucination sur les couts ou technologies.
Reponse : Analyse structuree, ancree dans le contexte reel, avec un raisonnement verifiable a chaque etape.

TEMPLATE CHAIN-OF-THOUGHT — A ADAPTER A VOTRE SECTEUR
Tu es un expert en [VOTRE DOMAINE] en Afrique de l'Ouest.

Analyse le probleme suivant : [VOTRE PROBLEME EN 1 PHRASE].
Reflechis etape par etape :

Etape 1 : Identifie la cause principale du probleme dans le contexte de [VOTRE LIEU].
Etape 2 : Decris l'obstacle principal qui empeche une solution classique de fonctionner.
Etape 3 : Propose une solution technologique accessible a [VOTRE PERSONA].

Developpe chaque etape avant de conclure.
