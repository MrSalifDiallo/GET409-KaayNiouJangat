| **C'EST QUOI LE VALUE PROPOSITION CANVAS ?** |

Le VPC, c'est un outil visuel avec 2 côtés qui doivent s'aligner parfaitement.

|  |  |  |
| --- | --- | --- |
| **👤 CÔTÉ GAUCHE — Profil Client** | **💡 CÔTÉ DROIT — Proposition de Valeur** |  |
| **🔧 Jobs To Be Done**  Ce qu'Abdoulaye essaie d'accomplir au quotidien.  **😣 Pains**  Ses frustrations, obstacles et risques réels.  **🌟 Gains**  Ses aspirations et définition du succès. | **📦 Produits & Services**  Les fonctionnalités concrètes de votre MVP.  **💊 Pain Relievers**  Comment votre solution réduit chaque Pain.  **🎁 Gain Creators**  Comment votre solution crée chaque Gain. |  |

|  |
| --- |
| **✅ LE FIT — Le VPC est réussi quand chaque Pain a son Pain Reliever et chaque Gain a son Gain Creator.** |

|  |
